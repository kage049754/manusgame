# Repository Description

Dungeon Dealer is an offline-first 2D gothic-fantasy blackjack RPG roguelite built with Godot 4 and GDScript for Android. Survive five lethal card duels using blackjack strategy, Trump Cards, passives, and combos. Includes Knight, Rogue, and Dealer class paths, escalating enemies, a final boss, local saves, and a dark black/crimson/ivory/gold table aesthetic. Online PvP is a future phase after the offline game is stable.
